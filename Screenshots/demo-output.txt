── 4. Conflicts found before anyone pays for an answer
   request: Explain it in at most 2 sentences, across at least 3 paragraphs.
   ✗ at most 2 sentences / at least 3 paragraphs: at least 3 paragraphs need at least 3 sentences, more than at most 2 sentences allows
   request: Mention "latency" in the answer. Never use the word "latency".
   ✗ use "latency" / don't use "latency": "latency" is both required and ruled out
   request: Return valid JSON as a bulleted list, all in lowercase and all caps.
   ✗ a bulleted list / valid JSON: valid JSON cannot be a markdown list
   ✗ all lowercase / all uppercase: an answer cannot be all lowercase and all uppercase
